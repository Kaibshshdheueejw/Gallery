# Sample media attribution

The bundled demo library (`public/media/*.jpg`) is generated by `scripts/prepare-media.mjs`
from low-resolution search thumbnails saved under `image-search/` — used purely as test
fixtures for this prototype, not as product content.

Sources (as returned by image search): Pexels, Unsplash, Vecteezy, PeakPX, The Photo Argus,
The Spruce Eats, Digital Photography School, Organic Headshots, and stock-agency preview
servers (iStock/Getty/Shutterstock/123RF/Dreamstime/eBay/Pinterest). Watermarked previews were
excluded where visible; thumbnails are downscaled to ≤1000 px.

Screenshots (`scr-1…6`) are synthetic SVG UI mocks generated in
`src/data/datasources/screenshots.ts` — no third-party content.

Before shipping any real product, replace this fixture set with properly licensed assets or
the user's own media (the Flutter app reads the device media store instead).
